## Learning Path

1. **Start with traffic fundamentals:** Explore packet and NetFlow analysis.
2. **Investigate network alerts:** Practice reviewing proxy, IDS/IPS, and firewall evidence.
3. **Analyze remote connections:** Study VPN tunnel and SSH activity.
4. **Explore application protocols:** Investigate POP3, IMAP, SMTP, and FTP traffic.
5. **Study encrypted web connections:** Finish with HTTPS investigation, following the lab's stated prerequisites and capabilities.

## How to Use the Labs

1. Open the official lab using its direct link.
2. Review the learning objectives and environment requirements.
3. Follow the lab instructions in an authorized environment.
4. Record relevant packets, log events, timestamps, and observations.
5. Summarize findings and identify possible defensive improvements.
